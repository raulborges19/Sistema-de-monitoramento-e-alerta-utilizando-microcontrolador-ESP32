# Sistema-de-monitoramento-e-alerta-utilizando-microcontrolador-ESP32
Este projeto desenvolve um sistema de monitoramento com ESP32 capaz de detectar movimentação por sensores e enviar alertas em tempo real. Ao identificar um evento, o microcontrolador aciona um alarme sonoro e envia notificações via Telegram, utilizando a conectividade Wi-Fi para monitoramento remoto.
